# apt packages for the maritime project (gz-maritime, ehukai, and the
# vehicle model repositories).
#
# Hand-maintained on purpose. The source tree is not in the image, so
#
#     drydock run rosdep install --from-paths src --ignore-src -y
#
# against the mounted workspace is what AUTHORITATIVELY resolves dependencies.
# This list just means you rarely have to wait for it. When rosdep installs
# something here, add it to this file so the next image build has it.
#
# Syntax: one package per line, # comments, ${ROS_DISTRO} is substituted.

# ---- ehukai build dependencies --------------------------------------------
# These are here for ehukai, the spectral wave library, and nothing else —
# which is worth stating, because libimath-dev and libtbb-dev are otherwise
# unexplainable lines in a maritime package list.
#
# ehukai is built from source in the workspace like everything else, so the
# image needs what its CMakeLists looks for but not the library itself.
cmake
build-essential
libeigen3-dev
libtbb-dev
libimath-dev

# ---- misc -----------------------------------------------------------------
libbluetooth-dev
libcwiid-dev

# check_urdf and friends. A <test_depend> of the *_description packages, so it
# is only needed for `colcon test` — but this image is where those tests run.
# The rosdep key is spelled the same as the apt package, which is a coincidence
# rather than the libtbb-dev mistake repeated: `urdfdom` is a different key and
# resolves to ros-${ROS_DISTRO}-urdfdom, the library rather than the tools.
liburdfdom-tools
